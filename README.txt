VERCEL DEPLOYMENT
-----------------
1. Extract this ZIP.
2. Upload the files/folder to your GitHub repository.
3. In Vercel, choose "Add New Project".
4. Import your GitHub repository.
5. Framework Preset: Other / no framework.
6. Build Command: leave empty.
7. Output Directory: leave empty (or use the project root).
8. Deploy.

IMPORTANT
---------
Make sure index.html is in the ROOT of the repository.

CONTACT FORM
------------
The contact form is now a static JavaScript demo. It validates the form and shows a success message, but it does not send a real email. This is intentional so the portfolio works on static hosting such as Vercel.

The original PHP version is still separate and can be used with XAMPP if PHP is required for your class.
